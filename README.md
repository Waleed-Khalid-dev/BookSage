# Agentic Coding - Portable AI Kit

This folder contains a universal, modular `.agent` configuration that can be used across any project (web development, C++, Python, etc.).

## How to use:
1. Copy the `.agent` folder from this directory.
2. Paste it into the root of any new project directory.
3. Start a new chat session with your AI assistant. The assistant will automatically load the workspace rules, coding standards, and memory system.
