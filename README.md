# BookSage Studio

BookSage is an advanced, self-contained desktop reading and learning studio built with Tauri, React, and Python.

## Core Features
- **AI-Powered Notes:** Automatically extracts structured chapter-by-chapter insights using AI (Gemini, OpenAI, Claude).
- **Immersive PDF Reader:** Features side-by-side spread views, smart margin cropping, and robust annotations (highlights, drawing, sticky notes).
- **Interactive Notes Viewer:** Renders AI-extracted JSON into beautiful Obsidian-style markdown, with flashcards and text-to-speech.
- **AI Copilot:** A persistent intelligent assistant available via right-click or floating UI to summarize, translate, explain, and rewrite any text.
- **Local-First Privacy:** All chat sessions and extracted notes are persisted to a local SQLite database.
